# gruvbox-steam

A Gruvbox-themed Windows 95 style for Steam Millennium.

Based on [ricewind012/win95-themes](https://github.com/ricewind012/win95-themes) with pixora icons and Terminus font.

## Credits

- **ricewind** – original [win95-themes](https://github.com/ricewind012/win95-themes)
- **tsora1603** – [pixora-icons](https://github.com/tsora1603/pixora-icons)

## Installation

1. Install [Millennium](https://github.com/SteamClientHomebrew/Millennium)
2. Clone this repo into `~/.local/share/Steam/millennium/themes/`
3. Select "Gruvbox Steam" in Millennium settings
