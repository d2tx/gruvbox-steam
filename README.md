# steam95

A Windows 95-styled theme for Steam Millennium, based on [ricewind012/win95-themes](https://github.com/ricewind012/win95-themes).

## Features

- Gruvbox color scheme
- Pixora pixel-art icons replacing default Windows ones
- Terminus font throughout the UI
- Includes all original color options (Default, Hotdog Stand, VGUI, Windows 2000)

## Credits

- **ricewind** – original [win95-themes](https://github.com/ricewind012/win95-themes) for Steam, Discord, Firefox, and VS Code
- **tsora1603** – [pixora-icons](https://github.com/tsora1603/pixora-icons)

## Installation

1. Install [Millennium](https://github.com/SteamClientHomebrew/Millennium)
2. Clone this repo into `~/.local/share/Steam/millennium/themes/`
3. Select "Windows 95" in Millennium settings
4. Under Colors, choose "Gruvbox"
